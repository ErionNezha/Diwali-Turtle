# 🪔 Diwali-Turtle

Happy Diwali me Python turtle — simulim i animuar në canvas: rangoli shumëngjyrëshe rrotulluese, fishekzjarrë, llamba diya me flakë dhe urimi Happy Diwali.

## 🚀 Si ta hapësh

Hap `index.html`, kliko **Live Demo** — animimi luhet automatikisht. Origjinali ekzekutohet me `python3 Happy_Diwali_in_Python_Turtle.py`.
